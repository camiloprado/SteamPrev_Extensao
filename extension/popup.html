Previsão de Preços ML

  1. Instalar o Docker Desktop se ainda não tiver (deixe o app aberto).
  2. Clonar ou abrir este repositório (SteamPrev_Extensao) no computador.
  3. (Opcional) Na raiz, um ficheiro .env com ITAD_API_KEY se quiser histórico de preços. Sem a chave a API ainda corre, com histórico limitado. Se o Compose exigir .env, copie .env.example.
  4. No terminal, na raiz do projeto, rode o comando abaixo. Só o serviço api é necessário (o dashboard na porta 8501 é opcional).
  5. Esperar o 1.º download dos modelos (~1,5 GB). O /health só fica healthy depois — a primeira vez é lenta.
  6. URL da API em ⚙️ = http://localhost:8000 (padrão).
  7. Recarregar a extensão em chrome://extensions se precisar.
  1. A URL em ⚙️ não é localhost — o serviço na nuvem está offline ou a acordar. O Chrome não liga o Docker da sua máquina.
  2. Espere 1–2 minutos e clique de novo em Verificar / ligar API. No Render Free o contentor dorme aos 15 min; o despertar pode baixar de novo ~1,5 GB de modelos.
  3. Confirme a URL HTTPS em ⚙️ (sem barra no final) e teste Abrir API Docs.
  4. Caminho a $0: mude a URL em ⚙️ para http://localhost:8000 e ligue o Docker local com o comando abaixo.

O overlay na página da Steam só funciona com a API a correr.

docker compose up -d api
